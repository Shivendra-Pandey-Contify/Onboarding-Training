--------------------------------------------------------------

5. PERMISSIONS AND OWNERSHIP
--------------------------------------------------------------
chmod 755 deploy.sh              # rwxr-xr-x
chmod 644 deploy.sh              # rw-r--r--
chmod +x deploy.sh               # add execute for everyone
chmod u+x deploy.sh              # add execute for owner only
chmod go-w file.txt              # remove write from group and others
sudo chown user:group file.py    # change owner and group

Values: r=4  w=2  x=1
  755 rwxr-xr-x  scripts, executables, directories
  644 rw-r--r--  normal files
  600 rw-------  private files (keys, secrets)
  777 rwxrwxrwx  AVOID, insecure

Calculation:
  755 -> Owner 4+2+1=7 (rwx) | Group 4+0+1=5 (r-x) | Others 4+0+1=5 (r-x)
  644 -> Owner 4+2+0=6 (rw-) | Group 4+0+0=4 (r--) | Others 4+0+0=4 (r--)

Script permission example:
touch backend/deploy.sh
ls -l backend/deploy.sh          # -rw-r--r--  (not executable)
chmod 755 backend/deploy.sh
ls -l backend/deploy.sh          # -rwxr-xr-x  (executable)
chmod 644 backend/deploy.sh      # back to 644


6. PROCESS MANAGEMENT
--------------------------------------------------------------
ps aux                       # all running processes
ps aux | grep python         # find python processes (grep shows itself too)
pgrep -af python             # cleaner: PIDs + full command lines
top                          # live monitor (q to quit)
lsof -i :8000                # what is using port 8000
kill PID                     # SIGTERM (15): graceful shutdown
kill -9 PID                  # SIGKILL (9): force kill, last resort

Prefer kill PID. Use kill -9 only if the process does not respond.

Example (two terminals):
  Terminal 1:  sleep 300
  Terminal 2:  ps aux | grep sleep     # shows sleep 300 (PID 11673) + grep
               kill 11673
               ps aux | grep sleep     # only grep line remains

ps aux columns:
  USER owner | PID process id | %CPU %MEM usage | STAT state (S sleeping,
  R running, + foreground) | COMMAND what started it

top reading:
  load average: 0.23, 0.10, 0.05    load over 1/5/15 min (low = idle)
  Tasks: 240 total, 1 running       process counts
  %Cpu(s): ... 96.3 id              96.3% CPU idle
  MiB Mem: 3886.1 total, 255.8 free RAM (buff/cache is reclaimable)
  MiB Swap: ... 1442.8 used         swap in use = RAM pressure

11. MISTAKES AND LESSONS
--------------------------------------------------------------
1.  cd desktop -> No such file: case-sensitive. Use cd ~/Desktop, press Tab.
2.  ls a -> cannot access: wrong path. Read the error, it names the path.
3.  ls project failed, ls projects worked: check spelling with ls first.
4.  cd ../logs failed: .. is home, not linux-practice. Use cd logs.
5.  less -/practice.txt: typed -/ instead of ~/.
6.  Loop wrote ~/practice.txt, not in current dir: ~ is home.
    Use ./practice.txt or > practice.txt.
7.  >> python.tx created stray file: >> silently creates files.
    Fix: rm ~/linux-practice/python.tx
8.  cat > notes.txt merged with prompt: press Enter, then Ctrl+D.
9.  cd ~m / ~n / ~h failed: ~name means ANOTHER USER'S home.
10. grep "ERROR" returned nothing: case-sensitive, use grep -i.
11. ps aux | grep sleep shows 2 lines: grep matches itself.
    Use pgrep -af sleep  or  grep "[s]leep".
12. /dev/sda1 at 100%: mounted live ISO, read-only, ignore.
